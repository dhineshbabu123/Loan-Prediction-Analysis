# Loan Prediction Analysis 
## Project Overview
This project predicts whether a loan will be approved or not based on applicant details using machine learning techniques.
## Objective
To analyze loan applicant data and build a predictive model that helps financial institutions make better decisions.
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
## Dataset
The dataset contains details like:
- Applicant Income
- Loan Amount
- Credit History
- Education
- Gender
- Marital Status
## Steps Involved
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Encoding
4. Model Training
5. Model Evaluation
## Result
The model predicts loan approval status with good accuracy.
## How to Run
1. Clone the repository
2. Install requirements
3. Open the notebook and run all cells
